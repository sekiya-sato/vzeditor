# VZ Editor

VZEditor was originally forked from [LZ Editor](https://github.com/TouryuTamane/lz-editor) developed by Touryu Tamane.

VZEditor has since evolved into an independent project with its own architecture, features, and development roadmap.

本プロジェクトは、Touryu Tamane氏が開発したLZ Editorを起源としています。
現在は独自の設計、機能、開発方針を持つ独立したプロジェクトとして開発を進めています。
具体的にはClaudeCodeとCodex、GithubDesktop などと連携する機能など。

We thank the original author and contributors for their work.

## 開発方針

- 高速起動・軽量動作、GPU（OpenGL）による描画
- VZ Editor のキー操作の継承と、サクラエディタ互換のキー割り当ての両立
- 日本語入力（IME）への対応
- Windows 11 / Linux / macOS のクロスプラットフォーム対応
- ウィンドウの最前面固定・背景透過など、作業の横に置いて使うための機能
- 前回のモニター・位置・サイズで起動（モニターを外した場合は主モニターに表示）
- 2画面ファイラーの機能拡張

## フォーク元との関係

- このリポジトリ（[sekiya-sato/vzeditor](https://github.com/sekiya-sato/vzeditor)）は [TouryuTamane/lz-editor](https://github.com/TouryuTamane/lz-editor) のフォークです。フォーク元のコミット `adab5d2` までの履歴を含み、それ以降の変更がこのリポジトリ独自のものです。
- フォーク後に追加・変更した機能は、Windows 11 の実機と WSL2 の Linux で動作確認しています。macOS は GitHub Actions でのビルド・テスト・起動の確認のみで、実機の画面操作は未確認です。
- 実行ファイル名は `lz` から `vz` に、パッケージ名は `vzeditor` に変えています。原作と同時にインストールしても衝突しません。
- デザインはvzeditorを踏襲します。ただしうろ覚えなので違うところもあるかもしれません。
- 不具合報告や要望は、原作由来の部分も含めてこのリポジトリの Issue へお願いします。
- フォーク元の更新を取り込む場合:

```powershell
git remote add upstream https://github.com/TouryuTamane/lz-editor.git
git fetch upstream
git merge upstream/main
```

## 追加機能

| キー | 機能 |
| :--- | :--- |
| `Alt+T` | 最前面固定の切替 |
| `Alt+W` | 長い行をウィンドウ幅で折り返して表示する / しないの切替 |
| `Alt+↑` / `Alt+↓` | 背景を濃く / 薄く（20〜100%、10% 刻み） |
| `Alt+0` | 背景透過を解除（100%） |
| `Alt+Shift+「+」` / `Alt+Shift+「-」` | 文字を濃く / 薄く（20〜100%、10% 刻み） |
| `Alt+Shift+0` | 文字透過を解除（100%） |
| `Alt+C` → `C` / `Alt+C` → `X` | バッファ全体を Claude Code / Codex のデスクトップアプリへ送信 |
| `Alt+C` → `N` / `Alt+C` → `M` | Claude Code / Codex のデスクトップアプリで新規セッション（アプリを前面にして Ctrl+N を押す） |
| `Alt+C` → `P` | GitHub Desktop で表示中のリポジトリを Push（GitHub Desktop を前面にして Ctrl+P を押す） |
| `Alt+K` | ターミナルの表示 / 元の画面へ戻る（Windows は WSL2 の既定シェル、Linux / macOS は bash） |
| `Alt+B` | 簡易ブラウザの表示 / 元の画面へ戻る（エディターで HTML・SVG を編集中なら、そのファイルを表示・再読み込み） |
| `Ctrl+T` / `Ctrl+W`（ブラウザ） | ブラウザの新しいタブ / このタブを閉じる |
| `Ctrl+Tab` / `Ctrl+Shift+Tab`（ブラウザ） | ブラウザの次 / 前のタブ |
| `Alt+F` / `Alt+R` / `Alt+G` / `Alt+J` | 検索 / 置換 / Grep / 指定行へジャンプ（エディター画面のみ） |
| `Alt+N` / `Alt+Shift+N` | 次を検索 / 前を検索 |
| `Enter` / `Shift+Enter`（エディター） | 改行して前の行の行頭の空白（タブ・半角スペース）を引き継ぐ（自動インデント） / 引き継がずに行頭から始める |
| `Shift+Enter`（2画面ファイラー） | カーソル位置のファイルを OS の関連付けで実行する |

ステータスバー右端の `TOP`・`背 n%`・`字 n%`、メニュー「ツール」からも操作できます。背景と文字の濃さは別々に変えられます。設定は次回起動時に復元されます。

複数ファイルは、ウィンドウへのドラッグ＆ドロップ、`vz a.txt b.md` のような起動引数、メニュー「ファイル」→「ファイルを開く...」（サクラ互換は `Ctrl+O` も。複数選択可）、2画面ファイラーで Space マーク → Enter のいずれでもまとめて開けます。

エディターで `Enter`（VZ 互換は `Ctrl+M` も）を押すと、改行した新しい行の先頭に、元の行の行頭にあるタブ・半角スペースを同じ並びで入れます。カーソルが行頭の空白の途中にあるときは、カーソルより前の分だけを入れます。全角スペースは引き継ぎません。インデントを付けずに改行するときは `Shift+Enter` を押します。元に戻す（Undo）は改行とインデントを1回で戻します。

Windows の2画面ファイラーでは、左右の見出しにフォルダを `C:/folder` や `//server/share` の形で表示します。

2画面ファイラーで `Shift+Enter` を押すと、カーソル位置のファイルを OS の関連付けで実行します。エクスプローラーでダブルクリックしたのと同じで、`.bat`・`.exe` は実行し、`.pdf` などは既定のアプリで開きます。フォルダはエクスプローラー（macOS は Finder）で開きます。作業フォルダはファイルのあるフォルダです。マークしたファイルは対象にしません。macOS は `open`、Linux は `xdg-open` を使います。

未保存の変更（新規バッファへの入力を含む）がある状態で終了しようとすると、×ボタンや Alt+F4 でも「保存して終了 / 保存せず終了 / キャンセル」を確認します。

実行ファイルを更新するときは、`vz --save-and-quit` で起動中の vz に終了を要求できます（未保存のファイルは保存し、無題の内容は設定フォルダに一時保存）。置き換え後に `vz --restore` で起動すると、開いていたファイルと無題の内容が元どおりに開きます。2画面ファイラーの左右のフォルダ位置も戻り、表示中だった場合はファイラーを開きます。ターミナルとブラウザも開いていれば戻ります（ブラウザはタブごとに同じ URL と選択中のタブ、ターミナルは同じフォルダでシェルを新しく起動。実行中のコマンドや画面の内容は戻りません）。vz での編集中に外部でもファイルが変更されていた場合は上書きせず、vz の編集内容を無題のバッファに残し、再起動後に差分を表示してどちらを採用するか確認します。

エディターで表示中のファイルが外部で変更されると、再読み込みするか確認します（Y で再読み込み、N / ESC でそのまま）。別のタブの変更は、そのタブを表示してから確認します。

### 文字コードと巨大ファイル

- **文字コード**: UTF-8・UTF-8 BOM・Shift_JIS（CP932）を自動で判定して開き、同じ文字コードで保存します。ステータスバーに文字コードと改行コードを表示します。メニュー「ファイル → 文字コードを指定して保存...」またはステータスバーの文字コードのクリックで、文字コードを選んで保存できます。保存先の文字コードで表せない文字があれば保存せず、その位置（行・桁）を表示します。
- **巨大ファイル**: 128MB 以上のファイルは巨大ファイルモードで開きます（ステータスバーに `[巨大]`）。10GB のファイルも約 0.2 秒で表示します。
  - ファイルは読み込まずにメモリへ対応付け（mmap）、行の位置の索引を裏で作ります（10GB で 1〜数秒。ステータスバーに「索引 nn%」）。索引ができた範囲はすぐに表示・編集でき、それより先への移動（行ジャンプ・末尾へ）は索引が届いたら行います。
  - 編集・Undo（200 回まで）・範囲選択・コピー（16MB まで）は通常のファイルと同じキーで行えます。追加した文字は別に持つので、編集してもメモリはほとんど増えません。
  - 保存は裏で行い、ステータスバーに「保存中 nn%」と出します（10GB で数秒。保存中は編集できません）。同じフォルダの一時ファイルに書いてから置き換えます。保存した後も Undo できます。ハードリンクのあるファイルは、置き換えるとリンクが切れるので、保存する前に確認します。
  - 検索（次・前）・すべて置換・Grep は裏で並列に行い、実行中に `Esc` を押すと中止します（索引待ちの行ジャンプも同じ）。すべて置換は、置換した結果を同じフォルダの作業ファイル（`.<名前>.vzwork-….tmp`）に書き出してから入れ替え、1 回の Undo で戻せます。そのまま保存するときは作業ファイルを置き換えるだけなので、すぐ終わります（BOM を付ける・文字コードを変えるときを除く）。作業ファイルは使わなくなったら消します。
  - 折り返し表示（`Alt+W`）は、画面に入る行だけを折り返します。上下の移動は表示行単位（ページ移動は通常のファイルと同じく論理行単位）、スクロールバーは論理行の割合です。行ジャンプの「折り返し単位」は使えません。
  - 巨大ファイルでは、Markdown ビュー・該当行マーク・バッファ全体の送信（Alt+C）は使えません。長い行（数十 MB）は画面に入る範囲だけを読んで表示します。
  - 画面の「保存して終了」でも、ハードリンクのある巨大ファイルを置き換える前に確認します。`vz --save-and-quit` ではハードリンクのある巨大ファイルを元のまま保ち、編集内容を設定フォルダに一時保存します。ファイルの保存に失敗した場合も同様です。一時保存にも失敗した場合（すべて置換の結果を含む場合など）は、理由を表示して終了を中止します。`vz --restore` で編集を当て直します。元ファイルが変わっていた場合は一時保存が残ります。
  - ネットワークドライブなどで対応付けできないファイルは、2GB 以下ならメモリに読み込んで開きます（ステータスバーに `[巨大・メモリ読込]`）。
  - 対応付け中のファイルを他のアプリが書き換えないでください（Windows は切り詰めを拒みますが、Linux / macOS では異常終了することがあります）。

エディターのファイルタブは、ファイル名をドラッグして別のファイルタブの位置にドロップすると並べ替えられます。名前のあるファイルのタブをダブルクリックすると、拡張子付きのファイル名をコピーします。

### ターミナルと簡易ブラウザ

ファイルを編集しながら、`Alt+K` でターミナル、`Alt+B` でブラウザに切り替えて確認できます。同じキーでもう一度押すと元の画面（エディター / ファイラー）へ戻ります。メニュー「ツール」からも切り替えられます。ターミナルは 1 つ、ブラウザはタブで複数開けます。一度開くとバッファ帯のファイルのタブの後ろに「ターミナル」「ブラウザ」（複数なら「ブラウザ1」「ブラウザ2」…）のタブが並び、クリックで切り替えられます。

- **ターミナル**: 初めて開いたときに、編集中のファイルのフォルダ（無題ならファイラーのフォルダ）でシェルを起動し、切り替えても動き続けます。Windows は WSL2 の既定のディストリビューション・既定のシェル（`wsl.exe`。無ければ Git Bash、PowerShell）、Linux / macOS は bash です。環境変数 `VZ_TERMINAL_SHELL` で別のシェルを指定できます。
  - `Alt+T` などの Alt 系の共通キーを除き、キーはすべてシェルへ送ります（`Ctrl+C` は中断、F キー・矢印も送る）。
  - `Ctrl+V` / `Shift+Ins` で貼り付け、マウスでドラッグして離すと選択した文字をコピー（エディターの `Ctrl+V` などで貼り付けられます）、`Ctrl+Shift+C` で選択範囲（選択が無ければ見えている画面）の文字をコピー、マウスホイールで履歴（5000 行）を表示します。日本語入力もできます。
  - `exit` などでシェルが終了すると、ターミナルを閉じてタブも消し、元の画面へ戻ります。もう一度 `Alt+K` で新しく起動します。
- **簡易ブラウザ**: Windows は WebView2、macOS は WKWebView をウィンドウに埋め込みます。上の欄に URL・ファイルのパス・`localhost:3000` などを入れて Enter で開きます。
  - エディターで HTML・SVG を開いた状態で `Alt+B` を押すと、そのファイルを表示します（そのファイルを表示中のタブがあれば再読み込み、無ければ新しいタブで開く）。表示するのは保存済みの内容です。
  - `Ctrl+T` または「+」で新しいタブ、`Ctrl+W` または「×」でタブを閉じます（最後のタブを閉じると元の画面へ戻る）。`Ctrl+Tab` / `Ctrl+Shift+Tab` でタブを切り替えます。`target="_blank"` のリンクも新しいタブで開きます。
  - `F5` 再読み込み、`Alt+←` / `Alt+→` 戻る / 進む、「外部ブラウザ」で既定のブラウザで開きます。
  - ページの上では背景透過は効かず、メニューやダイアログを開いている間はページを隠します。Cookie などは設定フォルダの `webview` に保存します。
  - Linux は埋め込めないため（WebView が GTK のウィンドウを必要とし、Wayland の winit ウィンドウに入れられない）、「外部ブラウザ」で開きます。

## キー割り当て

エディター画面のキー割り当ては「サクラ互換」（既定）と「VZ 互換」を切り替えられます。切替はメニュー「ツール」→「キー割り当て」です。2画面ファイラーのキーと、上の Alt 系のキーはどちらでも同じです。

画面下端の F キー欄は、ウィンドウ幅に余裕があれば F12 まで、狭いときは F10 まで表示します（F11・F12 は現在割り当てなし）。Shift・Ctrl・Alt のどれか 1 つを押している間は、その組み合わせの割り当て（`SF1`・`CF1`・`AF1` など）に切り替わります。

| | サクラ互換 | VZ 互換 |
| :--- | :--- | :--- |
| Shift | `SF3` 前を検索、`SF8` コピー、`SF10` 行の複製 | `SF3` 前を検索、ほかは F キーと同じ |
| Ctrl | `CF3` 行マーク切替、`CF4` 閉じる | `CF3` 空欄、`CF4` 閉じる、ほかは F キーと同じ |
| Alt | `AF4` 終了 | `AF3` 空欄、`AF4` 終了、ほかは F キーと同じ |

エディターの `F4` 単独は両方式で空欄です。2画面ファイラーの F キー欄は `AF4`（終了）を除き、修飾キーを押しても通常の割り当てを表示します。

| 操作 | サクラ互換（既定） | VZ 互換（原作） |
| :--- | :--- | :--- |
| 新規 / 開く | `Ctrl+N`・`F2` / `Ctrl+O` | `F2` / メニュー「ファイル」 |
| 上書き保存 / 名前を付けて保存 | `Ctrl+S` / `Ctrl+Shift+S` | `F10`・`Ctrl+K` → `D` / メニュー |
| ファイル（現在のバッファ）を閉じる | `Ctrl+F4`（未保存なら確認） | 同左 |
| 挿入 / 上書きの切替 | `Ins`（上書き時はカーソルが文字の下半分） | 同左 |
| 元に戻す / やり直し | `Ctrl+Z` / `Ctrl+Y` | メニュー |
| 切り取り / コピー / 貼り付け | `Ctrl+X`・`F7` / `Ctrl+C`・`F8` / `Ctrl+V`・`F9`（選択なしは現在行） | なし / なし / `Ctrl+V` |
| 範囲選択 | `Shift`+移動キー、`F6`、`Ctrl+A`、`Ctrl+W`、マウス | なし |
| 行の切り取り / 削除 | `Ctrl+E` / `Ctrl+Shift+E` | なし / `Ctrl+Y`・`F6` |
| カーソル移動 | 矢印、`Ctrl+←→` 単語、`Home` / `End`、`Ctrl+Home` / `End` | ダイヤモンドカーソル `Ctrl+E/S/D/X`、`Ctrl+A` / `Ctrl+F`・`F7` / `F8` 単語、`Ctrl+R` 前ページ、`F5` 行末、`Ctrl+Q` → `S/D/R/C` |
| バッファ切替 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | `Ctrl+W` / `Ctrl+Shift+W` |
| 2画面ファイラー | `Esc`（選択中は選択解除） | `Esc`・`F9`・`Ctrl+K` → `Q` |
| Markdown 編集 / ビュー切替 | `Ctrl+Shift+V`・`Ctrl+P` | `Ctrl+P`・`Alt+P`・`Ctrl+K` → `V` |
| ヘルプ / バージョン情報 | `F1` / `Ctrl+Shift+F1`（クリックでも閉じる） | `F1` / メニュー（同左） |
| フォントサイズ | `Ctrl++` / `Ctrl+-` / `Ctrl+0` | 同左 |

全キーの一覧は `F1`、対応状況は [docs/キー割り当て対比.md](docs/キー割り当て対比.md) を参照してください。

### 検索・置換・Grep・行ジャンプ

| 操作 | サクラ互換 | VZ 互換 |
| :--- | :--- | :--- |
| 検索 / 置換 | `Ctrl+F` / `Ctrl+R` | `Alt+F` / `Alt+R` |
| Grep / 指定行へジャンプ | `Ctrl+G` / `Ctrl+J` | `Alt+G` / `Alt+J` |
| 次を検索 / 前を検索 | `F3`・`Alt+N` / `Shift+F3`・`Alt+Shift+N` | 同左 |
| 該当行マークの切替 | `Ctrl+F3` | メニュー「検索」 |

`Alt+F` / `R` / `G` / `J` はサクラ互換でも使えます。メニュー「検索」からも各機能を開けます。

- **検索**: ダイアログでは Enter または F3 で下検索、Shift+Enter または Shift+F3 で上検索。大文字・小文字の区別、単語単位、正規表現、先頭／末尾からの再検索を選べます。検索は行単位で、改行をまたぐ一致は探しません。見つかった文字列は選択され、ダイアログを開き直しても検索条件は残ります（別の文字列を選択して開くと、それが検索条件になります）。
- **置換**: 「置換」は選択中の一致を置き換えて次の一致を選択します（一致を選択していなければ、まず次の一致を選択）。「すべて置換」はファイル全体、または選択範囲内を一括で置き換え、1回の Undo で戻せます。正規表現では置換後に `$1` や `${name}` が使えます。クリップボードの内容で置き換えることもできます。
- **該当行マーク**: 検索条件に一致する行の行番号の横に印を付けます。文書を編集すると消えます。
- **Grep**: 保存済みのファイル（UTF-8・UTF-8 BOM・Shift_JIS）を検索します（読めないファイル・バイナリは読み飛ばし、結果は最大 2,000 件）。128MB 以上のファイルは読み込まずに対応付けて調べます。対象・除外の名前パターンは `*.rs;*.md` のようにセミコロンで区切ります。既定では `.git`・`target` などのフォルダと実行ファイル・画像などを除外します。結果は検索場所からの相対パスで表示し、クリックすると、そのファイルを開いて該当位置へ移動します。検索中は「検索を中止して閉じる」で止められます。
- **指定行へジャンプ**: 行番号は1始まり。折り返し表示中は、改行単位か画面の折り返し単位かを選べます。

ダイアログは Esc で閉じます。

## 入手

[Releases](https://github.com/sekiya-sato/vzeditor/releases) に、`v` で始まるタグごとに各 OS 向けのビルドを公開します（GitHub Actions で自動ビルド）。

| ファイル | 対象 |
| :--- | :--- |
| `vz-windows-x86_64.exe` | Windows 11（x86_64） |
| `vz-macos-aarch64` | macOS（Apple Silicon） |
| `vz-linux-x86_64` / `vz-linux-aarch64` | Linux |
| `*.deb` / `*.rpm` | Ubuntu・Debian / Fedora など（`/usr/bin/vz` とデスクトップ登録） |

## ビルド

```powershell
git clone https://github.com/sekiya-sato/vzeditor.git
cd vzeditor
cargo build --release
```

- Windows: MSVC ツールチェーン（Visual Studio の「C++ によるデスクトップ開発」と Windows SDK）が必要です。
- Linux: 日本語フォント（`fonts-noto-cjk` など）と、ファイルダイアログ用に `zenity` を推奨。
- macOS: 追加の依存はありません。

ソースは Cargo ワークスペースで、ルートの `vz`（起動）と `crates/` の vz-ui（画面）・vz-platform（OS 固有処理）・vz-config（設定）・vz-core（編集モデル）に分かれています。詳細は [docs/基本設計.md](docs/基本設計.md) を参照してください。

## macOS での検証

開発機（Windows 11）では macOS 版のリンクと実行ができません（macOS SDK は Apple 製ハードウェアでしか使えません）。手元でできるのは型チェックまでで、テスト・ビルド・起動の確認には GitHub Actions の macOS ランナーを使います。

手元の型チェック（`cargo check` / `cargo clippy`）には Clang が要ります。依存の `objc2-exception-helper` が Objective-C のファイルを 1 つコンパイルするためです。Visual Studio Installer で「Windows 用 C++ Clang コンパイラ」を追加し、次のように実行します（パスは VS 2026 Community の例）。

```powershell
$llvm = 'C:\Program Files\Microsoft Visual Studio\18\Community\VC\Tools\Llvm\x64\bin'
$env:CC_aarch64_apple_darwin = "$llvm\clang.exe"
$env:AR_aarch64_apple_darwin = "$llvm\llvm-ar.exe"
cargo check --all-targets --target aarch64-apple-darwin
```

- ワークフロー: [.github/workflows/macos-ci.yml](.github/workflows/macos-ci.yml)（手動実行のみ）。Actions タブの「macOS CI」→「Run workflow」で実行し、ランナー（`macos-latest` = Apple Silicon / `macos-15-intel` = Intel）と起動確認の有無を選びます。
- 実行内容: `cargo check --all-targets` → `cargo clippy --all-targets` → `cargo test` → `cargo build --release` → release ビルドを 15 秒起動して画面を撮る。
- 結果: 実行ページの Summary に段階ごとの ✅ / ❌ / ⏭ が出ます。すべて通ればジョブは緑で「✅ macOS CI 成功」、どれかが失敗すればジョブは赤で、失敗した段階とエラーの抜粋が出ます。
- 引き継ぎ: 成果物 `macos-ci-report-…` の `handoff.md`（結果の表・環境・エラー抜粋）を、修正するエージェントや開発者にそのまま渡します。各段階の全ログと起動時の画面も同じ成果物に入っています。
- ワークフローはリポジトリにファイルを作らず、コミットも push もしません（レポートはランナーの一時フォルダに置きます）。
- 透過・キー入力・IME・ドラッグ＆ドロップなど、画面を操作する確認は macOS の実機が必要です。実機で確認するまでは「macOS 実機未確認」の扱いです。
