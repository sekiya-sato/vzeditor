# キー割り当て対比（VZ Editor 現行 ⇔ サクラエディタ）

VZ Editor のキー割り当てをサクラエディタに合わせるための調査結果。

## 決定事項と実装状況

- 方式: 設定で「サクラ互換（既定）」と「VZ 互換」を切り替える。下表の「VZ Editor（現行）」列は VZ 互換のときの割り当て。
- 2画面ファイラーは Esc（選択中は選択解除を優先）、Markdown 切替は Ctrl+Shift+V（Ctrl+P も可）。
- 背景の濃さ（Alt+↑ / ↓）は現行のまま（矩形選択は未実装のため）。
- F2 / F3 はサクラ互換でも VZ と同じ（F2 新規、F3 開く）。サクラ互換の F4 は現在のバッファを閉じる（Ctrl+F4 と同じ）、F5 は割り当てなし。サクラのブックマーク・画面分割・再描画には割り当てない。
- Ins は両方式で挿入 / 上書きの切替（上書き時はカーソルが文字の下半分）。
- ターミナル（Alt+K）と簡易ブラウザ（Alt+B）は両方式共通。ターミナル表示中は Alt 系の共通キー以外をすべてシェルへ送る（サクラ互換・VZ 互換の割り当ては効かない）。
- 段階1（キーの付け替え）と段階2（範囲選択・切り取り・コピー・選択の置き換え）を実装済み。行・単語単位の切り取り、行の二重化も実装済み。実装済みのキーの一覧は [基本設計.md](基本設計.md) の「キー割り当て」。
- 未実装: 段階3の選択範囲のインデント・ソート・空白削除、段階4のブックマーク、段階5の矩形選択など。

## 実装量の目安

1. キーの付け替えだけで済むもの（○）: 保存・開く・新規・名前を付けて保存、Undo / Redo、Ctrl+← / →、Ctrl+Home / End、Ctrl+Tab、行削除など。数時間程度。
2. 範囲選択（Shift+移動、Ctrl+A、ダブルクリック、選択の描画）とクリップボード連携（切り取り・コピー・選択の上書き）: サクラ互換の土台。最優先かつ最大の作業。
3. 選択を使う編集（インデント、行の二重化、行・単語単位の切り取り、ソート、空白削除）。
4. ブックマーク（検索・置換・Grep・行ジャンプは実装済み）。
5. 矩形選択など（挿入 / 上書きモードは実装済み）。

## 決めること（残り）

- 段階3以降の優先順位。
- 矩形選択を実装する場合の、背景の濃さ（Alt+↑ / ↓）の移動先。
