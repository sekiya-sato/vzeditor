# VZ Editor 基本設計

## 目的

原作 [LZ Editor](https://github.com/TouryuTamane/lz-editor)（MIT License）の VZ 互換操作・2画面ファイラー・Markdown ビューを引き継ぎ、次を追加する。

- Windows 11 / Linux（Ubuntu 24 など）/ macOS の3 OS 対応
- 背面透過（背景）と文字透過（前景）を個別に調整
- 最前面固定
- 上記とフォントサイズの設定保存

## 確定事項

### 背面透過

- ウィンドウは常に透過可能（`with_transparent(true)`）で作成し、クリア色は完全透明にする。
- 透過するのは背景色のみ。文字・カーソル・行番号・ダイアログ・メニューのポップアップは不透明。
- 対象の背景: エディター本文・行番号欄・現在行・スクロールバー溝、Markdown ビュー、ファイラー全体、メニューバー、ステータスバー、バッファ帯、ファンクションキー欄。
- 不透明度は 20〜100%、10% 刻み。初期値 100%。

| 操作 | 内容 |
| :--- | :--- |
| `Alt+↑` | 背景を濃く（+10%） |
| `Alt+↓` | 背景を薄く（-10%） |
| `Alt+0` | 透過解除（100%） |
| ステータスバー `透過 n%` | 左クリックで薄く（20% の次は 100% に戻る）、右クリックで濃く |
| メニュー「ツール」 | 濃く / 透過 / 解除 |

### 文字透過

- 前景（文字・行番号・カーソル・ボタン類）の不透明度を背景とは別に 20〜100%、10% 刻みで変更する。初期値 100%。
- メニューバー・ステータスバー・バッファ帯・F キー欄・本文（エディター / Markdown / ファイラー）の内容に `Ui::multiply_opacity` を掛ける。各帯の背景は内容の外側（Frame）で塗るため影響を受けない。本文内で塗る背景は `bg_painter()` で文字透過の影響を外す。
- ダイアログ（ヘルプ・About・ファイラー操作）とメニューのポップアップは常に不透明。

| 操作 | 内容 |
| :--- | :--- |
| `Alt+Shift+「+」` | 文字を濃く（+10%） |
| `Alt+Shift+「-」` | 文字を薄く（-10%） |
| `Alt+Shift+0` | 文字透過の解除（100%） |
| ステータスバー `文字 n%` | 左クリックで薄く（20% の次は 100% に戻る）、右クリックで濃く |
| メニュー「ツール」 | 濃く / 透過 / 解除 |

「+」「-」は物理キーで判定する（US 配列 `=+`、JIS 配列 `;+`、JIS の Shift+「-」が `=` になる場合も「-」扱い）。

#### キーの重複確認

| キー | 用途 | 重複しない理由 |
| :--- | :--- | :--- |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | フォントサイズ（原作） | Alt 併用時は反応しない |
| `Alt+P` | Markdown 切替（原作） | 文字・背景のキーは P を使わない |
| `Alt+T` / `Alt+↑↓0` | 最前面・背景 | Shift なしのときだけ反応 |
| `Alt+C` → `C` / `X` | Claude Code / Codex へ送信 | C は透過・最前面のキーで使っていない。2打目は Alt+C の直後だけ有効 |
| `Alt+Shift+「+」「-」0` | 文字 | Shift ありのときだけ反応 |

単体テスト `test_window_style_keys_do_not_overlap` で上記を確認する。Windows の言語切替（左 Alt+Shift のみ押して離す）は、間に「+」などを押すと発動しない。

### 最前面固定

- `Alt+T`、ステータスバーの `TOP` ボタン、メニュー「ツール」→「最前面に固定」で切替。
- `ViewportCommand::WindowLevel(AlwaysOnTop / Normal)` を送る。起動時は保存値で `with_always_on_top()` を指定。

### キー割り当て（サクラ互換 / VZ 互換）

- エディター画面のキー割り当てを「サクラ互換」と「VZ 互換」から選ぶ。既定（設定ファイルが無いとき）はサクラ互換。
- 切替: メニュー「ツール」→「キー割り当て: … へ切替」、またはステータスバー右端の `サクラ` / `VZ` ボタン。設定に保存し、次回起動時に復元する。VZ 互換に切り替えると範囲選択は解除する。
- 2画面ファイラーのキー、Alt 系（透過・最前面・送信）はどちらでも同じ。
- サクラ互換の割り当ては利用中の `sakura.ini`（既定値）に合わせる。調査と全体の対比は [キー割り当て対比.md](キー割り当て対比.md)。

サクラ互換で実装済みのキー（段階1・2）:

| 分類 | キー |
| :--- | :--- |
| ファイル・バッファ | Ctrl+N 新規、Ctrl+O 開く、Ctrl+S 上書き保存、Ctrl+Shift+S 名前を付けて保存、Ctrl+Tab / Ctrl+Shift+Tab バッファ切替 |
| 編集 | Ctrl+Z 元に戻す、Ctrl+Y やり直し、Ctrl+X / Shift+Del / F7 切り取り、Ctrl+C / Ctrl+Ins / F8 コピー、Ctrl+V / Shift+Ins / F9 貼り付け、Del / BkSp、Ctrl+BkSp / Ctrl+Del 単語の左・右を削除、Ctrl+E 行切り取り、Ctrl+Shift+E 行削除、Ctrl+K（Shift）行末まで切り取り（削除）、Ctrl+U（Shift）行頭まで、Ctrl+D（Shift）単語、Ctrl+I / Shift+F10 行の二重化 |
| 移動 | 矢印、Ctrl+← / → 単語、Home / End、Ctrl+Home / End ファイル先頭・末尾、PgUp / PgDn、Ctrl+PgUp / PgDn 半ページ、Ctrl+↑ / ↓ 1行スクロール |
| 範囲選択 | Shift+移動キー（Ctrl+Shift+← → Home End、Ctrl+Shift+↑ ↓ は2行ずつ）、Ctrl+A すべて選択、Ctrl+W 単語選択、F6 範囲選択開始（移動キーで選択を広げる）、マウスのドラッグ・Shift+クリック・ダブルクリック（単語）・トリプルクリック（行）、Esc 選択解除 |
| 表示・その他 | F1 ヘルプ、Ctrl+Shift+F1 バージョン情報、Ctrl++ / Ctrl+- / Ctrl+0 / Ctrl+ホイール フォントサイズ、Esc 2画面ファイラー（選択中は解除が優先）、Ctrl+Shift+V（と Ctrl+P）Markdown 編集 / ビュー切替 |

- 選択中の文字入力・貼り付け・Enter・Del・BkSp は選択範囲を置き換える（アンドゥは1回で戻る）。
- 切り取り・コピーは選択が無ければ現在行（改行を含む）が対象（サクラの「選択なしでコピー / 切り取り」と同じ）。
- 未対応のサクラのキー（検索・置換・Grep・行ジャンプ、F2〜F5・F10〜F12 など）は、ステータスバーに未対応と表示する。
- 制約: egui は Ctrl+Shift+V を貼り付けとして届けるため、クリップボードが空のときは Markdown 切替が反応しない（メニューか Ctrl+P を使う）。

### Claude Code / Codex への送信

vz で書いた指示を、起動中の Claude Code / Codex のデスクトップアプリへ送って送信する。

| 操作 | 送信先 |
| :--- | :--- |
| `Alt+C` → `C` | Claude デスクトップアプリ（Claude Code） |
| `Alt+C` → `X` | Codex デスクトップアプリ |
| メニュー「ツール」→「Claude Code へ送信」「Codex へ送信」 | 同上 |

- 送るのは現在のバッファ全体（末尾の空行は除く）。空なら送らない。送信後もバッファの内容は残し、フォーカスを vz に戻す。
- 2打目は Alt を押したままでも離してもよい。`C` / `X` 以外のキーを押すと取り消す。2打目は Alt+C の直後だけ有効なので、VZ 互換の Ctrl+X などとは重ならない。
- 両アプリとも外部から入力欄へ文字を渡す API が無いため、キー操作で送る。
  1. Alt などの修飾キーが離されるのを待つ（押したままだと Ctrl+V が Ctrl+Alt+V になる。3 秒で打ち切り）
  2. 対象アプリのウィンドウを探して前面にする
  3. クリップボードに本文を入れて貼り付け、送信キーを押す（Claude Code は Enter、Codex は Ctrl+Enter。macOS の Codex は Cmd+Enter）
  4. 元のクリップボード（テキストのみ）を戻し、vz を前面に戻す
- 処理は別スレッドで行い、結果（送信した文字数、またはエラー）をステータスバーに出す。

| OS | ウィンドウの探し方 | 貼り付け・送信 |
| :--- | :--- | :--- |
| Windows | 実行ファイルで判定。Claude: `Claude.exe`、Codex: `OpenAI.Codex` パッケージ内の `ChatGPT.exe`（同名の ChatGPT アプリには送らない） | SendInput で Ctrl+V → Enter（Codex は Ctrl+Enter） |
| macOS | アプリ名 `Claude` / `Codex` を activate | osascript（System Events）で Cmd+V → Return（Codex は Cmd+Return）。アクセシビリティの許可が必要 |
| Linux（X11） | xdotool でウィンドウクラス `Claude` / `Codex` を検索 | xclip と xdotool で Ctrl+V → Return（Codex は Ctrl+Return）。Wayland は非対応 |

- 確認状況: Windows で Claude Code（Enter）と Codex（Ctrl+Enter）への送信をユーザーが確認済み。macOS（Cmd+Enter）と Linux は未確認。
- 制約: アプリ内のフォーカスが入力欄にあることが前提（前面化すると直前にフォーカスしていた要素に戻る）。Claude アプリは表示中のセッションへ送る。クリップボードの画像など、テキスト以外の内容は戻らない。

### 複数ファイルを開く・ドラッグ＆ドロップ

すべての経路を `open_paths()` に集約し、次の規則で開く。

- ファイルはそれぞれバッファで開き、最初に開いたファイルを表示する。既に開いているファイルは新しいバッファを作らず切り替えるだけにする。
- 起動直後の未編集の [無題] バッファは、最初に開いたファイルで置き換える。
- 開けなかったファイルはステータスバーに名前を出し、残りは開く。
- フォルダだけが渡された場合は、ファイラーでそのフォルダへ移動する。

| 経路 | 内容 | 対応 OS |
| :--- | :--- | :--- |
| ドラッグ＆ドロップ | ウィンドウへ複数ファイルをドロップ。ドラッグ中は「ドロップして n 個のファイルを開く」を重ねて表示 | Windows / macOS / Linux（X11） |
| 起動引数 | `vz a.txt b.md ...`。エクスプローラーで複数ファイルを `vz.exe` に重ねた場合も同じ。存在しないパスは新規ファイルとして開く | 全 OS |
| 開くダイアログ（F3） | 複数選択可（Windows: rfd、macOS: osascript の multiple selections、Linux: zenity `--multiple` / kdialog `--multiple`） | 全 OS |
| 2画面ファイラー | Space でマークした複数ファイルを Enter でまとめて開き、マークを解除する。マークが無ければ従来どおりカーソル位置を開く | 全 OS |

- 保存ダイアログや確認ダイアログの表示中にドロップされた場合は開かず、ダイアログを閉じるよう案内する。
- Linux の Wayland は winit がドラッグ＆ドロップに未対応のため対象外。macOS で Finder の「このアプリケーションで開く」や Dock アイコンへのドロップ（Apple Event）は未対応。

### 終了時の保存確認

- 未保存の変更（既存ファイルの修正、新規バッファへの文字入力）があるバッファが1つでもあれば、終了前に確認ダイアログを出す。未入力の新規バッファだけなら確認せずに終了する。
- 対象の終了操作: F10（ファイラー）、メニュー「ファイル」→「終了」、ウィンドウの×ボタン、Alt+F4、macOS の Cmd+Q。OS からの終了要求は `close_requested` を受けて `CancelClose` で止める。
- ダイアログには未保存のバッファ名を並べ、次の3択とする。

| ボタン | キー | 動作 |
| :--- | :--- | :--- |
| 保存して終了 | Enter / Y | パスのあるバッファを上書き保存し、無題のバッファは1つずつ「名前を付けて保存」を開く。すべて保存できたら終了 |
| 保存せず終了 | N | 変更を破棄して終了 |
| キャンセル | ESC | 終了しない |

- 保存ダイアログのキャンセルや保存エラーの場合は終了を中止し、ステータスバーに理由を出す。
- 保存ダイアログを開いている間に×ボタンが押された場合は終了せず、ダイアログを閉じるよう案内する。

### 設定保存

`settings.ini`（`key=value` 形式）に `opacity`・`text_opacity`・`always_on_top`・`font_size`・`key_scheme`（`sakura` / `vz`）を変更の都度保存する。

| OS | 保存先 |
| :--- | :--- |
| Windows | `%APPDATA%\vzeditor\settings.ini` |
| macOS | `~/Library/Application Support/vzeditor/settings.ini` |
| Linux | `$XDG_CONFIG_HOME/vzeditor/settings.ini`（未設定時 `~/.config/...`） |

### OS 別の実装

| 機能 | Windows | macOS | Linux |
| :--- | :--- | :--- | :--- |
| ファイルダイアログ | rfd（IFileDialog） | osascript | zenity → kdialog |
| メニューからの貼り付け | arboard | arboard | wl-paste / xclip / xsel |
| 日本語フォント | BIZ UDゴシック → MS ゴシック → 游ゴシック → メイリオ | Osaka → ヒラギノ角ゴ | fc-match → 既定パス |
| コンソール | リリース版は非表示 | - | - |

ダイアログが使えない場合は原作同様、組み込みのパス入力欄に切り替える。
